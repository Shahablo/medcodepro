CMS Finalized 2027 Spine Osteotomy Values. The Operative Note Still Has to Tell the Story.

Four spine osteotomy codes receive finalized Medicare work values for 2027. A code-level review starts with the documented procedure, not a specialty-wide payment estimate.

MedCode Pro Editorial · November 23, 2026 · 3 min read

A specialty average cannot tell a spine group what happened to a particular procedure code. The 2027 Medicare Physician Fee Schedule final rule gives a more useful example: four posterior spine osteotomy codes with revised guidance and finalized work values. The first question for a practice is whether its operative notes clearly describe the work it is asking a human coder to evaluate.[1]

What CMS actually finalized

CMS displayed the 2027 Physician Fee Schedule final rule on November 4, 2026, and it was published November 9. For CPT 22210, 22212, 22214 and add-on 22216, CMS finalized work relative value units of 23.12, 21.72, 19.53 and 3.00, respectively, as proposed. The policy takes effect January 1, 2027. These are work RVUs, not dollar payment rates or a forecast for any one practice.[1]

The rule describes revised CPT guidance for this code family, including the extent of ligament and bony resection involved in realigning the spinal column. CMS did not simply accept the specialty panel’s higher recommended work values for the first three codes. It weighed surveyed intraservice time and assumptions about postoperative visits; commenters disputed parts of that reasoning. The final values settle the 2027 Medicare valuation decision, not whether a particular operation met a code’s requirements.[1]

Put the code, date and operative evidence together

For a spine group, the practical review is narrower than applying a headline percentage to every case. Identify historical cases involving the osteotomy family, keep the service date and code version attached, and have a qualified coder compare the full operative note with the applicable code descriptors and guidelines. The note should support what was actually performed, at which level and with what separately reportable work; the reviewer must resolve that question rather than infer it from a planned procedure or a payment table.[1]

A work RVU change also does not by itself establish a claim denial or a final allowed amount. A Medicare professional payment comparison needs the relevant 2026 and 2027 code-level inputs, conversion factor, locality, service setting and actual practice mix. Commercial contracts and any facility payment are separate. Keep those calculations with the reimbursement team rather than treating the finalized work values as a revenue prediction.[1][2]

  1. Version the rule. Keep the 2027 final-rule code family and the code set applicable on the service date.
  2. Review the note. Ask which operative details support the proposed code and which details remain uncertain.
  3. Separate the outcomes. Documented work, coding, Medicare valuation and an actual payer response are different findings.
